# Portfolio (oswwwaldo)

This project uses Astro.js, TypeScript, React.js, SCSS, GSAP, Figma and Vite. I am using Github Issues to track the incoming workflow and necessary changes/implementations so if you want to stay tuned, hit the watch button!
