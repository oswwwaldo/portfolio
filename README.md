
# Portfolio (oswwwaldo)

This project uses Vite, Astro.js, TypeScript, React.js, SCSS and GSAP.

The design for this website was inspired by many other portfolios and works including... [Gianluca Gradogna](https://www.gianlucagradogna.com/), [Ali Zafar Iqbal](https://alizafariqbal.com/), [National Design Studio](https://ndstudio.gov/) and their [White House.gov (2026)](https://www.whitehouse.gov/), [Camille Mormal](https://camillemormal.com/), [Bamoj Studio's Saisei](https://saisei-sbj.webflow.io/) and many more!

## Themes

[ ] Andrea Laszlo De Simone
    Defined by moving video, noise and grain—adopt black color setup

[ ] ASCII
    Defined by ascii art clash with light/dark modes

[ ] Light
    With an eggshell white background and charcoal black for text

[ ] Dark
    With a charcoal background with eggshell white for text

[ ] Sketchpaper
    Defined by rough sketches, crumpled paper edges and lines—adopt light color setup

[ ] Yoji Shinkawa
    Inspired from a rough gray background for interactions, a beige for background and clean black for text coupled with ink art
