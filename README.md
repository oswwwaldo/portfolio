# Oswaldo Fabrizio De Los Santos Ascencio' Portfolio

This project uses Astro.js, TypeScript, React.js, SCSS, GSAP, Figma and Vite. I am using Github Issues to track the incoming workflow and necessary changes/implementations. Because I want to do so much, this will probably take me until Summer 2027 to finish and even then I still have many ideas for things I'd like to add onto this site, it is definitely a passion and labor of love. This project has served as my introduction back into web development after what felt like a ten-year hiatus, it marks the first time I used TypeScript, Astro.js, GSAP, Three.js and this new-kind of workflow. It is also the first time I've made a music player, made a properly responsive website or deployed to Cloudflare live to production.

While it won't win any awwwards, and I wouldn't want it to—a lot of my inspiration comes from those sorts of websites except I asked the question, what if they were user-friendly? UI/UX is a big concern for me and I hope I delivered.

The design for this website was inspired by many other portfolios and works, including: [Gianluca Gradogna](https://www.gianlucagradogna.com/), [Ali Zafar Iqbal](https://alizafariqbal.com/), [National Design Studio](https://ndstudio.gov/) and their [White House.gov (2026)](https://www.whitehouse.gov/), [Camille Mormal](https://camillemormal.com/), [Bamoj Studio's Saisei](https://saisei-sbj.webflow.io/), and many, many more...

In the future I hope to make a Three.js component to my website that allows visitors to enter the world of Westeros in a small but fun arcade game that I always wanted to play from a browser. That is definitely long-term especially since I would want to hand-code 95% of it but it will be done someday.

This is mostly for fun website despite its nature.

I started building this in late July 2026.
